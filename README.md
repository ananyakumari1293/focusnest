# 🌊 About FocusNest

FocusNest is a modern productivity workspace designed for students, developers, and self-learners.

Instead of switching between multiple applications for planning, focus sessions, AI assistance, collaboration, and music, FocusNest brings everything together into a single calming environment.

### ✨ What FocusNest Offers

* 🤖 AI Study Assistant powered by Gemini
* 📋 Kanban Task Management
* ⏱️ Pomodoro Focus Sessions
* 👥 Collaborative Study Rooms
* 🎵 Spotify Integration
* 🔐 Secure Authentication
* ☁️ Cloud-Based Workspace
* 📱 Responsive Modern UI

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/ananyakumari1293/focusnest.git

cd focusnest
```

### Install Dependencies

```bash
npm install
```

### Create Environment Variables

Create a `.env` file:

```env
VITE_GEMINI_API_KEY=your_gemini_api_key

VITE_SPOTIFY_CLIENT_ID=your_spotify_client_id

VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

### Run Development Server

```bash
npm run dev
```

### Build For Production

```bash
npm run build
```
